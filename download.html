Installing Retirology

After purchase, Lemon Squeezy emails you a link to the installer for your OS, plus access to the customer portal for re-downloads. The steps below walk through running it.

macOS Windows Linux

macOS

Apple Silicon and Intel builds are signed and Apple-notarized. Install in three steps:

  1. Open the downloaded .dmg.
  2. Drag Retirology to your Applications folder.
  3. Double-click to launch. The first time you open it, macOS shows a one-time "Retirology is an app downloaded from the Internet, are you sure you want to open it?" dialog — click Open. After that, it launches normally every time.

Where your data lives

~/Library/Application Support/Retirology/retirology.db

Windows

  1. Run the downloaded .exe installer.
  2. SmartScreen prompt: click More info, then Run anyway.
  3. Follow the installer prompts. A shortcut goes to your Start menu.
  4. Launch from Start or your desktop.

Why the warning? Windows SmartScreen flags installers without an established reputation. As more people install Retirology the warning will go away on its own; an EV code-signing cert is on the post-launch roadmap.

Where your data lives

%APPDATA%\Retirology\retirology.db

Linux

  1. Make the downloaded AppImage executable: chmod +x Retirology-*.AppImage
  2. Double-click it, or run it from the terminal: ./Retirology-*.AppImage
  3. Optional: integrate it into your application menu with AppImageLauncher.

FUSE required. AppImage uses libfuse2. On Ubuntu 22.04+ install it with: sudo apt install libfuse2

Where your data lives

~/.config/Retirology/retirology.db
