Install steps

  1. Open the downloaded .dmg.
  2. Drag Retirology.app into your Applications folder.
  3. First launch: open Applications, right-click (or Control-click) Retirology, choose Open, then click Open in the Gatekeeper dialog.
  4. After that, launch normally from Spotlight, the Dock, or wherever you prefer.

Why the warning? macOS shows it for any app from a developer not yet enrolled in Apple's notarization program — including ours. We're working on Apple Developer ID notarization post-launch; the right-click → Open workaround is Apple's official path until then.

Windows

Windows 10 / 11

Retirology-Setup-2026.0.0.exe

64-bit installer

Install steps

  1. Run the downloaded .exe.
  2. SmartScreen prompt: click More info, then Run anyway.
  3. Follow the installer prompts. A shortcut goes to your Start menu.
  4. Launch from Start or your desktop.

Why the warning? Windows SmartScreen flags installers without an established reputation. As more people install Retirology the warning will go away on its own; an EV code-signing cert is on the post-launch roadmap.

Where your data lives

%APPDATA%\Retirology\retirology.db

Linux

x86_64 AppImage

Retirology-2026.0.0.AppImage

Works on most modern distros

Install steps

  1. Make the AppImage executable: chmod +x Retirology-2026.0.0.AppImage
  2. Double-click it, or run it from the terminal: ./Retirology-2026.0.0.AppImage
  3. Optional: integrate it into your application menu with AppImageLauncher.

FUSE required. AppImage uses libfuse2. On Ubuntu 22.04+ install it with: sudo apt install libfuse2

Where your data lives

~/.config/Retirology/retirology.db
